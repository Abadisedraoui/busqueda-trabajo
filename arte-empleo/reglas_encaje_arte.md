# Reglas de encaje — Arte Empleo

La puntuación orienta la revisión. No estima la probabilidad de contratación.

## 1. Encaje directo (0-4)

- 4: coincide claramente con formación, experiencia o práctica artística acreditada.
- 3: encaje fuerte mediante habilidades transferibles.
- 2: requiere adaptar portfolio/CV pero es razonable.
- 1: oportunidad exploratoria.
- 0: requisito esencial no acreditado.

## 2. Formato y viabilidad (0-3)

Valorar:
- Madrid / remoto razonable.
- Horario compatible.
- Duración del proyecto.
- Remuneración publicada.
- Materiales y desplazamientos.
- Necesidad de alta como autónoma.
- Deadline.

## 3. Valor para portfolio / carrera (0-3)

- Permite producir obra o material mostrable.
- Conecta arte con diseño, educación, cultura o espacio.
- Puede generar recurrencia, referrals o clientes.
- Da acceso a institución o red cultural relevante.

## Requisitos esenciales

Mostrar siempre de forma separada cualquier requisito no acreditado:
- titulación específica en Bellas Artes si se exige de forma excluyente;
- experiencia docente reglada obligatoria;
- experiencia profesional demostrable como muralista;
- conservación/restauración;
- carnet/vehículo si es imprescindible;
- alta de autónomos previa si se exige;
- equipo/material propio costoso;
- disponibilidad horaria incompatible.

## Etiquetas

- **Encaje directo**: merece revisión prioritaria.
- **Transferible**: experiencia cercana, requiere adaptar candidatura.
- **Exploratoria**: puede interesar por portfolio artístico aunque falte experiencia comercial específica.
- **No encaja**: requisito esencial incompatible.

## Para encargos y gigs

No penalizar por ausencia de trayectoria corporativa. Priorizar:
1. calidad/adecuación del portfolio;
2. técnica solicitada;
3. alcance y deadline;
4. remuneración;
5. materiales y logística;
6. derechos de uso de la obra;
7. posibilidad de cobrar anticipo / hitos;
8. claridad contractual.
